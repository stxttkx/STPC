# STPC Desktop Environment

STPC is a web application.
Plan:Simulate a desktop environment, offering a variety of practical tools and applications suitable for learning and daily using.

## Features ( and developing plan )

- [ ] **Desktop Interface**: Provide an intuitive desktop environment.
- [ ] **Applications**: Include commonly-used applications such as calculator, browser, file manager, notepad, and command-line tools.
- [ ] **System Tools**: Feature a task manager, settings center, music player, Minesweeper game, and more.
- [ ] **Personalization**: Support custom background images and startup sound effects.
- [ ] **Internationalization**: Support multiple languages.

## Directory Structure

- `desktop.html`: HTML files for the desktop environment, corresponding to the English and Chinese interfaces respectively.
- `icon/logo.png`: The icon of this project.
- `img/background.png`: Desktop background image.
- `media/startup.mp3`: Startup sound effect.
- `stylesheets/`: Stylesheet files.
- `desktop.js`: Function library implementing main interactive features.

## Usage Instructions

- [x] Open the `desktop.html` file to run in your browser.
- [ ] Click on desktop icons to launch the corresponding applications.
- [ ] Adjust personalization settings through the settings center.
